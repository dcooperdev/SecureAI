    *   **Puertos 135 (RPC) y 139 (NetBIOS)**: Aunque no se reportan con severidad `HIGH` directamente en `sensor_vulnerabilidades`, son puertos legacy de Windows que históricamente han sido blanco de múltiples exploits (e.g., MS08-067 para RPC, ataques basados en NetBIOS para enumeración y movimiento lateral). 2.  **Hardening de Servicios:**

        *   Configurar `postgresql.conf` para escuchar solo en `localhost` (127.0.0.1) o en interfaces de red específicas y seguras, no en `0.0.0.0`.

        *   Crear usuarios con los mínimos privilegios necesarios (`Least Privilege`).

3.  **Micro-segmentación de Red:** Implementar una segmentación de red para aislar el sistema `PC-DAVID` en una VLAN separada o aplicar reglas de firewall granularmente que restrinjan el tráfico solo a los activos que requieren comunicación con estos servicios.
4.  **Gestión de Vulnerabilidades:** Establecer un programa continuo de escaneo de vulnerabilidades y gestión de parches para identificar y remediar proactivamente las debilidades.
5.  **Principios de Mínimo Privilegio:** Asegurar que todos los servicios y aplicaciones se ejecuten con los privilegios mínimos necesarios.
6.  **Monitoreo y Detección:** Implementar herramientas de monitoreo de red y seguridad (SIEM, EDR) para detectar actividad maliciosa en los puertos expuestos y en el tráfico de red general.
