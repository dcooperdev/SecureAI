Instrucciones de Instalación

🪟 Windows

  1. Descarga el archivo galt_latest.zip
  2. Extrae el contenido en una carpeta de tu elección (ej: C:\Galt)
  3. Ejecuta galt.exe como Administrador
  4. Sigue el asistente de configuración inicial
  5. Galt comenzará a monitorear tu red automáticamente

🐧 Linux

  1. Descarga y extrae el archivo ZIP
  2. Abre una terminal en la carpeta extraída
  3. Ejecuta el script de instalación: 
    sudo bash install.sh
  4. Inicia el servicio: 
    sudo systemctl start galt

Requisitos del Sistema

  • Python 3.9+ (incluido en el paquete para Windows)
  • Permisos de administrador/root
  • Conexión a internet para activación
  • API Key de Gemini (se proporciona en configuración inicial)
